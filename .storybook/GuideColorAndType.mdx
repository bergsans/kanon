## Two typefaces, one rule

Serif is the collection's voice — the passage, the quote, a work's title.
Sans is the app's — buttons, labels, metadata, years. Real components, not
a specimen invented for this page:

<Story of={PassageAccordionStories.Open} />

<Story of={SearchBoxStories.Empty} />

Both tokens are plain OS system stacks today, chosen for being everywhere
rather than for how they look — see
[Foundations/Typography](?path=/docs/design-guide-foundations-typography--docs)
for candidate replacements, shown on these same two components.

## Which text may sit on which surface

Text needs a contrast of 4.5:1 and a control's outline needs 3:1. The figures
come from the measurements in the `@theme` comment; if a token changes, measure
again there first.

<ContrastPairs />

## Ink by role

Headings and quotes use `ink-900`. `body` sets `ink-800` as the default.
Secondary text such as rationales and titles uses `ink-600`. Metadata, counts,
placeholders and resting icons use `ink-400`, the one muted tone.

<InkByRole />

## Parchment by role

The page's ground and an unselected chip share `parchment-50`, and the sheet
(`parchment-0`) sits above both. The sheet is only a slightly lighter tone than
the ground, so the shadow does the work of separating them, not the color.

## Type scale

Every size is in `rem`, so the text-size setting scales the whole document
through a single lever: the root's `font-size`, at 80, 100 or 120%. A size
written in `px` isn't scaled by it.

Drama and verse get no hyphenation, because the poet chose where each line
breaks.

## Numerals

A number that lines up in a column, such as money, the stopwatch or the cost
table, uses `tabular-nums`. A number inside running text, such as a year or a
verse number inside the quote, uses old-style figures instead — set in the
serif face, the way a printed edition would set it.
